# صفحه پیام خصوصی

یک صفحه ساده که هنگام باز شدن سایت از بازدیدکننده می‌خواهد هر رمزی دلش خواست وارد کند. رمز بررسی نمی‌شود؛ با زدن دکمه، متن دلخواه درشت و وسط صفحه نمایش داده می‌شود.

## تغییر متن نمایشی

فایل `public/app.js` را باز کن و مقدار `MESSAGE` را تغییر بده:

```js
const MESSAGE = `متن دلخواه تو`;
```

فایل‌ها را در GitHub جایگزین کن و هاست را دوباره Deploy کن. این نسخه فقط صفحه نمایش پیام است و چت‌روم قبلی را نشان نمی‌دهد.
